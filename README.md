# 杨喻城 | Yuchen Yang 的个人主页

基于 [academic-homepage-template](https://github.com/senli1073/academic-homepage-template) 构建的单页个人主页。

- 在线地址：https://junliu3.github.io
- 内容配置：`contents/config.yml`（导航 / 标题 / 区块）+ `contents/*.md`（各区块正文）
- 头像：替换 `static/assets/img/photo.png`
- 背景图：替换 `static/assets/background/` 下的图片，并在 `contents/config.yml` 中更新列表
